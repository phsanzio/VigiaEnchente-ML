A literatura hidrológica não trata a escolha entre 7 ou 30 dias como uma escolha excludente, mas sim como duas representações de processos físicos em escalas temporais distintas:  

O que a literatura estabelece:
API de Curto Prazo (5 a 7 dias):

Processo: Focado na saturação da camada superficial do solo (primeiros centímetros) e no escoamento superficial direto (infiltração excedente).  

Uso típico: Microbacias urbanas, terrenos íngremes e estudos clássicos do SCS-CN (que utilizam a janela antecedente de 5 dias).  

API de Médio/Longo Prazo (14 a 30 dias):

Processo: Captura a umidade profunda da zona vadosa, a recarga do lençol freático e a sustentação da vazão de base do rio.

Python
import numpy as np
import pandas as pd


# 1. Função para calcular o API (forma recursiva diária)
def calcular_api(chuva_series, alpha=0.90):
  api_valores = np.zeros(len(chuva_series))
  api_atual = 0.0
  for i, p in enumerate(chuva_series):
    api_atual = alpha * (api_atual + p)
    api_valores[i] = api_atual
  return api_valores


# 2. Função para calcular o VPD via FAO-56 (Tetens)
def calcular_vpd(temp_max, temp_min, umidade_media):
  # Pressão de saturação para T_max e T_min (kPa)
  es_max = 0.61078 * np.exp((17.27 * temp_max) / (temp_max + 237.3))
  es_min = 0.61078 * np.exp((17.27 * temp_min) / (temp_min + 237.3))

  # Média diária de es
  es = (es_max + es_min) / 2.0

  # VPD em kPa
  vpd = es * (1.0 - (umidade_media / 100.0))
  return np.maximum(vpd, 0.0)  # Garante que não haja valores negativos

df['vpd_kpa'] = calcular_vpd(
    df['temp_max'], df['temp_min'], df['umidade_media']

import numpy as np
import pandas as pd


def calcular_api_janela(chuva_series, k_dias=30, alpha=0.90):
  """Calcula o API somando exatamente os últimos k_dias com decaimento alpha."""
  n = len(chuva_series)
  api_resultado = np.zeros(n)
  chuva_arr = chuva_series.to_numpy()

  # Pesos exponenciais: [alpha^1, alpha^2, ..., alpha^k]
  pesos = np.array([alpha**i for i in range(1, k_dias + 1)])

  for t in range(n):
    if t == 0:
      api_resultado[t] = 0.0
    else:
      # Pega a chuva dos dias anteriores até o limite k_dias
      inicio = max(0, t - k_dias)
      chuvas_passadas = chuva_arr[inicio:t][
          ::-1
      ]  # Inverte para o dia t-1 ser o primeiro

      # Aplica os pesos correspondentes aos dias disponíveis
      w = pesos[: len(chuvas_passadas)]
      api_resultado[t] = np.sum(chuvas_passadas * w)

  return api_resultado


# --- Aplicação no DataFrame ---

# API de 30 dias: olha os últimos 30 dias com alpha=0.90
